# Sokoban README
A simple 5-level puzzle game I made using Java Swing. This project was made by following steps from RyuSnow on youtube.
I altered some of his game mechanics to give my program its own identity.
But anyways heres the link if you want to watch the playlist that I followed through
https://www.youtube.com/watch?v=om59cwR7psI&list=PL_QPQmz5C6WUF-pOQDsbsKbaBZqXj4qSq

Goal of the game:
To complete the 5 level puzzle game by being a character that pushes a box towards an "end point".
Once the box is on the end point, the level will continue.

To Move:
W,A,S,D (assuming how they work)

How to run the game:
Download this file and put it into your IDE may it be VSCode, IntelliJ IDEA, or Apache Netbeans. Put it and simply run it without debugging.
(Its that simple.)

Yeah, thats about it.
